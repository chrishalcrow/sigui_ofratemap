# sigui openfield ratemap

An example (SpikeInterface-GUI)[https://github.com/SpikeInterface/spikeinterface-gui/] custom plugin, which takes in a position data as a (Pynapple)[] TsdFrame and plots an openfield rate map. Scroll through your spikes to see where your subject is in the field when that spike happened:

![An example of the sigui openfield rate map used in the GUI](http://url/to/img.png)

To use, install this repo in the same environment as spikeinterface-gui, then include the view using "ratemapview".

For an example, check out the Figure 5 example from the SpikeInterface-GUI paper repo!
